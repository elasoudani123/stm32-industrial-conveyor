# STM32-Based Industrial Conveyor Control System

> Independent Embedded Systems Project 
## Overview

This project explores the analysis and modernization of an existing industrial conveyor control system.

The work began by studying the existing conveyor equipment and its legacy Telemecanique TSX07 PLC-based control architecture. The objective was to understand the existing system, identify its limitations, and investigate a microcontroller-based alternative using STM32 technology.

The project combines industrial automation, embedded systems, sensor interfacing, actuator control, hardware prototyping, and circuit simulation.

---

## Project Motivation

The project started from an existing conveyor system that was no longer operational.

Rather than treating the equipment simply as a broken system, the project used it as an opportunity to investigate its control architecture, understand the role of the existing PLC and connected equipment, and explore how its control functions could be reproduced using a modern embedded architecture.

---

## Existing Industrial System

### Telemecanique TSX07 PLC

The original conveyor control system was based on a Telemecanique TSX07 PLC.

The existing architecture was studied to understand its role in processing system inputs and controlling the corresponding outputs.

## System Modernization

The project investigates the transition from the existing PLC-based control architecture toward a microcontroller-based embedded solution.

The modernization study focuses on:

- Understanding the existing control architecture
- Identifying practical limitations
- Selecting an appropriate embedded controller
- Interfacing industrial sensors
- Controlling the conveyor actuators
- Modeling and testing the proposed system
